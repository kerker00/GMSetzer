macOS commands used `--disable-sandbox` and isolated scratch/cache/config/security
directories, with `CLANG_MODULE_CACHE_PATH` and `SWIFTPM_MODULECACHE_OVERRIDE`
redirected to temporary directories. The extracted Swift 6.2 toolchain used
its own Testing module/runtime and the existing Command Line Tools macOS 14.4
SDK, as documented in [Portability](../../Portability.md); this does not prove
macOS 14 runtime support. The current Apple compiler used Xcode 27.2.

Linux checks ran on the owner's existing SSH host, Linux 7.3.3 x86-64, Swift
6.4.2, using only this package's sources, tests, scripts, required recorded
benchmark fixtures and licence files in a separate temporary directory.
No new VM/container, global installation or benchmark run was used.

At the initial preparation stage, GitHub-hosted workflows, the minimum-version
Linux suite, tag/release creation and versioned remote consumer resolution
were pending. These checks were subsequently completed below.
No fresh reference comparisons, performance measurements, Apple device/minimum
runtime checks or consumer application tests are claimed.

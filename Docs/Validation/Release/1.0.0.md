# GMSetzer 1.0.0 preparation checks

23 November 2026, branch `release/1.0.0`, based on merged M8
`5f813088bb036ff94c8dddc7e0d36432c6c68dc2` and the descriptive main
reconciliation `ef17912`. The owner confirmed PR #30's merge and requested
release preparation. No 1.0 tag, release or Swift Package Index submission
is created by these preparation changes.

## Prepared release contents

- `GMSetzerVersion.current` changes from `1.0.0-dev.1` to `1.0.0`; native
  provider identity follows that constant.
- The package retains Swift 6.2, all six products, zero runtime dependencies
  and the existing macOS 15 / iOS 18 / visionOS 2 deployment declarations.
  Only their provisional comment is finalised.
- `Docs/API/1.0.0.json` freezes exactly the reviewed module records from
  `1.0-candidate.json`: 610 real declarations and one historical grouping
  record. Neither the original inventory nor its expectations are reset.
  The compatibility checker selects the versioned baseline by default.
- Final release notes and versioned DocC installation/compatibility text are
  prepared. The repository README still identifies 0.6.0 as the published
  preview until the stable tag and publication exist.

Parser/renderer/analysis implementation, public signatures, grammar, profiles,
fixtures, protected IDs, dependency pins and performance budgets are unchanged.
Historical performance/resource receipts keep their measured source identities;
this preparation makes no fresh timing, allocation or peak-memory claim.

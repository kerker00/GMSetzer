# GMSetzer 0.5.0 preparation checks

20 November 2026, `release/0.5.0`, based on `d8262da` after M5 merged in
PR #22 (`c9543fe`). This preparation changes the parser/native-provider result
identity from `0.5.0-dev.4` to `0.5.0` and adds release documentation. Parser
grammar, products, runtime dependencies, workflows, fixtures and protected IDs
are unchanged. A candidate identity is not a published version tag.

macOS uses temporary scratch/cache/configuration/security and module-cache
paths outside the repository. Swift 6.2 uses its own Testing module/runtime
and the existing macOS 14.4 SDK; this is not a macOS 14 deployment claim.
The existing Linux host is x86-64, kernel 7.3.4, Swift 6.4.2. It receives only
package sources/tests, offline scripts, their recorded budget-test inputs and
licence files in a task-specific directory; no VM/container or installation
is used. Offline budget-script tests read recorded inputs and do not execute
a benchmark series.

The independent SwiftPM probe checks the umbrella product, candidate identity,
all M5 features, composed HTML including title math/footnotes, tokens, source
positions, outline, native analysis and strict-profile opt-in behavior. It is
a temporary command-line package, not a consumer application integration.

## Publication gates and limits

Preparation PR CI/review/merge and owner-confirmed tagging/publication remain
pending. No `v0.5.0` tag or GitHub release has been created by this work. An
exact-version SwiftPM resolution and tag-triggered release checks cannot be
claimed before that tag exists. The existing workflow will rerun both platform
jobs at the chosen tag and create a draft with no uploaded build assets.

No fresh selected-extension performance/allocation measurements, reference-tool
series, broad fuzzing, minimum Apple runtime/device checks or consumer UI checks
were run. These remain M6/consumer work and are not implied by this preview's
functional acceptance.

# GMSetzer 0.6.0 preparation checks

21 November 2026, `release/0.6.0`, based on accepted main
`0cf6690bd5d0bd8c7ae77802c310dcccaab58be3`, following M6 PR #24 (`a8a0351`).
The candidate changes `GMSetzerVersion.current` from `0.6.0-dev.1` to `0.6.0`
and adds release documentation. Parser/rendering implementation, package
manifest, dependencies, workflows, fixtures and protected IDs are unchanged.
No M7 commit, mutation test or scratch-buffer optimization is included.
At this initial preparation checkpoint, the candidate identity was not a
published tag; the publication record below completes the release sequence.

and 31 Python tests on macOS/Swift 6.2.3 and Linux/Swift 6.2. This is baseline
evidence, not execution of the release candidate.

The resource receipt describes the accepted M6 source. Its complete runtime
inventory is unchanged here; one file differs solely in the identity string.
The archived hashes are not rewritten to pretend they measured `0.6.0`.
This preparation adds no fresh speed/RSS/allocation claim.

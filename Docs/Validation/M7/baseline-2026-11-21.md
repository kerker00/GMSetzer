# M7 first complete performance baseline

21 November 2026, owner-authorised 72-case series at clean commit
`1edf1a4332b85b6e642d14ae1c0af99d172f4bb1` (`feature/m7-hardening`).
All cases complete and all four existing budget commands exit 0: six paired
CommonMark/GFM comparisons and nine frozen M2 variant checks pass. No limit,
runtime source, benchmark input or dependency version was changed.

Apple M2, eight logical CPUs, 16 GiB RAM; macOS 27.0.1 / Darwin 27.0.0,
Apple Swift 6.4.2, Xcode 27.2 toolchain. Host/compiler/lockfile match the
historical reference. SwiftPM uses native Release builds, no debug symbols,
isolated caches and the pinned `Tools/Package.resolved`.

prepared list, and the checkout and all 48 runtime/benchmark source hashes
remain unchanged after execution. Load averages are recorded before/after;
other user workloads were not managed, and thermal/power state was not
continuously monitored. Affinity and power settings were left unchanged.

## Remaining M7 scope

This is a baseline at unchanged runtime sources, not an optimization result.
Existing parser budgets pass, but the first series does not complete M7:
real selected-extension measurements, adversarial scaling/allocations and a
larger isolated fuzz/sanitizer campaign remain. The bounded mutation campaign
and 245-test local Debug/Release results remain separate correctness evidence;
minimum-Swift/Linux execution of the new tests still awaits validation/PR CI.
No source change, push, PR, tag or release is performed for this measurement.

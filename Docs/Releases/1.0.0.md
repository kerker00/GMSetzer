# GMSetzer 1.0.0

The first stable source API for GMSetzer, a pure Swift Markdown parser with
CommonMark, GitHub Flavored Markdown, exact source positions and safe-default
HTML. These notes are prepared ahead of publication; the
[release record](../Validation/Release/1.0.0.md) identifies executed checks
and the publication state.

## Included

- CommonMark 0.31.2 and GFM, with all protected 652 CommonMark / 672 pinned GFM
  examples. GFM includes tables, task lists, strikethrough, extended autolinks
  and rendering policies.
- Independently selected raw YAML/TOML front matter, named footnotes, opaque
  inline/display/fenced TeX, GitHub alerts and Obsidian-style callouts.
- Immutable validated trees over original UTF-8 bytes, optional source-spelled
  tokens, exact UTF-16/line/scalar conversion, outlines and snapshot-bound queries.
- Three opt-in native analysis rules, portable findings, explicit suggested
  fixes and English/German message lookup.
- Safe-default HTML and explicit renderer hooks. `MarkdownHTML.render` validates
  one parser configuration and composes standard selected footnote/admonition HTML.
- Progressive structural HTML groups from a complete document, with explicit
  whole-document fallbacks and caller-controlled consumption/cancellation.
- Six library products, DocC guides/API references, a frozen source API baseline
  and Swift Package Index documentation configuration. No runtime dependencies.

## Requirements and compatibility

Requires Swift 6.2 or later. Declared Apple deployment minimums are macOS 15,
iOS 18 and visionOS 2; Linux is supported. Build/test evidence and minimum-OS
runtime coverage have distinct scopes in the release record.

The [1.x source-compatibility contract](../APIStability.md) covers public
signatures, existing conformances, documented coordinate/ownership contracts,
extension/token/message identifiers and safe defaults. Source-breaking changes
require a major release. Binary ABI, in-memory layout, persistent tree schemas,
stable hash values and fixed timings are outside that contract.

## Installation

After publication, select the stable 1.x series with Swift Package Manager:

```swift
.package(url: "https://github.com/kerker00/GMSetzer.git", from: "1.0.0")
```

Depend on `.product(name: "GMSetzer", package: "GMSetzer")`, or select
`SetzerSyntax`, `SetzerParser`, `SetzerExtensions`, `SetzerHTML` or `SetzerAnalysis`.
GitHub supplies source ZIP and tar.gz archives; no binary assets or registry
are required.

```swift
import GMSetzer

let html = try MarkdownHTML.render("# Hello\n\n- [x] Done",
    parser: MarkdownParser(profile: .gfm))
```

Existing lower-level parsing/rendering APIs remain available. Front matter
retains its escaped HTML fallback unless a caller explicitly omits it; math
preserves TeX without bundling a rendering engine.

## Limits

Progressive output requires a complete parse and does not promise input
streaming, an interruptible parse, bounded peak memory or fixed device latency.
Native analysis is a three-rule subset, not a complete linter. Raw-HTML opt-ins
and hook output are caller trust boundaries. Historical benchmark ratios apply
to their recorded hosts/configurations; no general C-parity claim is made.

Further syntax, tree-processing conveniences and Markdown output are planned
in the [roadmap](../Roadmap.md), outside the 1.0 release scope.

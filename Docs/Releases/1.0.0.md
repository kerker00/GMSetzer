# GMSetzer 1.0.0 — draft

Release preparation only. No 1.0.0 tag or stable release has been published.
Do not remove this notice until the release gates in [M8Readiness](../M8Readiness.md)
have passed and the owner confirms the exact release commit and publication.

## Intended stable scope

- Pure Swift 6.2+ CommonMark and GitHub Flavored Markdown, with no runtime
  dependencies and all protected 652 CommonMark / 672 GFM examples.
- Optional raw YAML/TOML front matter, named footnotes, opaque TeX, GitHub
  alerts and Obsidian-style callouts, independently selected through profiles.
- Validated source-positioned syntax trees, opt-in source-spelled tokens,
  UTF-8/UTF-16/line/column conversion, outlines, native findings and suggested fixes.
- Safe-default HTML, explicit caller trust boundaries, and complete-document
  progressive groups with documented whole-document fallbacks.
- `MarkdownHTML.render` convenience entry points with strict configuration
  validation and standard selected footnote/admonition presentation.
- Six independently consumable products, DocC guides/API references, an API
  compatibility inventory and Swift Package Index documentation configuration.

The proposed 1.x compatibility policy is in [APIStability](../APIStability.md).
Swift 6.2, macOS 15, iOS 18 and visionOS 2 are the proposed supported minimums;
Linux remains supported. Final platform/API acceptance is part of the release review.

## Installation after publication

This example becomes resolvable only after the confirmed 1.0.0 tag exists:

```swift
.package(url: "https://github.com/kerker00/GMSetzer.git", from: "1.0.0")
```

Depend on `.product(name: "GMSetzer", package: "GMSetzer")`, or select a
lower-level product. Before publication, pin the existing 0.6.0 preview and
use its documented API; it does not contain the new `MarkdownHTML` facade.

## Limits

Progressive output requires a complete parse and does not promise input
streaming, an interruptible parse, bounded peak memory or fixed device latency.
Math has no bundled TeX renderer. Native analysis has three explicit rules,
not a full markdownlint implementation. Raw HTML opt-ins and hook output remain
caller trust boundaries. Historical benchmark ratios apply to their recorded
hosts/configurations; no general C-parity claim accompanies this release draft.

Validation for the exact release commit, successful minimum-compiler CI,
independent tagged consumption and automatic archive checks must be recorded
before publication. A GitHub release and Swift Package Index submission are
separate owner-confirmed publication actions.

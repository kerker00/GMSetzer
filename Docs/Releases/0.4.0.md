# GMSetzer 0.4.0

First versioned preview of the standalone, MIT-licensed Swift Markdown library,
covering milestones M1–M4. Requires Swift 6.2 or later. APIs may change before 1.0.

## Included

- CommonMark 0.31.2: all 652 specification examples pass by exact HTML.
- GitHub Flavored Markdown: all 672 pinned specification examples pass,
  including tables, task lists, strikethrough, extended autolinks and tag filtering.
- Original UTF-8 source ranges, optional syntax tokens, UTF-16/line/column
  conversion and a document index with heading outline.
- Configurable HTML rendering with safe defaults, source anchors and renderer hooks.
- Three opt-in native analysis rules with portable findings and suggested edits.
- Six Swift package products with no runtime dependencies: `GMSetzer`,
  `SetzerSyntax`, `SetzerParser`, `SetzerExtensions`, `SetzerHTML`, `SetzerAnalysis`.

## Swift Package Manager

```swift
.package(url: "https://github.com/kerker00/GMSetzer.git", exact: "0.4.0")
```

Add `.product(name: "GMSetzer", package: "GMSetzer")` to the consuming target.
While the repository is private, GitHub read access is required. Publishing
this release does not change repository visibility automatically.

## Scope and limitations

This release distributes source only. GitHub provides ZIP and tar.gz archives;
there are no binary assets or application builds. Swift Package Manager fetches
the tagged Git repository and builds the library for the consumer's platform.

Footnotes, front matter, math, alerts and callouts remain planned for M5.
The native analysis rules are a documented subset, not a complete linter.
Analysis default messages are English. Block-quote and list marker syntax
tokens remain follow-up work. Apple minimum runtime/device verification and
new performance measurements are not established by CI; see the project plan
and existing validation records for their evidence and limits.

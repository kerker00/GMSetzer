# GMSetzer 0.5.0

Source-only preview of the standalone Swift Markdown library, adding M5
extensions and editor-facing follow-ups to 0.4.0. Requires Swift 6.2 or later.
APIs may change before 1.0.

## New since 0.4.0

- Opt-in raw YAML/TOML front matter with typed format/content access, exact
  original bytes/ranges and independently selectable formats.
- Named footnotes with parsed Markdown bodies, forward/repeated references,
  first-call numbering, finite cyclic-note handling and composed HTML backlinks.
- Opaque inline, dollar-display and `math` code-fence TeX nodes. Callers choose
  formula rendering through hooks; no TeX engine or JavaScript is bundled.
- GitHub-style alerts and Obsidian-style callouts, including parsed Markdown
  titles, type aliases, folding metadata and optional `<details>` HTML.
- Original quote/list marker tokens with exact item ownership and continuation
  prefixes, available only when syntax collection is enabled.
- Optional English/German native finding/fix text lookup, structured heading
  arguments and explicit caller-selected language/fallback behavior.
- Prepared inline matchers, document/quote-start contexts and validated token
  owner remapping for extensions that rebuild trees.

CommonMark 0.31.2 retains all 652 protected examples and the pinned GFM corpus
retains all 672. The six SwiftPM products still have no runtime dependencies:
`GMSetzer`, `SetzerSyntax`, `SetzerParser`, `SetzerExtensions`, `SetzerHTML` and
`SetzerAnalysis`.

## Swift Package Manager

```swift
.package(url: "https://github.com/kerker00/GMSetzer.git", exact: "0.5.0")
```

Add `.product(name: "GMSetzer", package: "GMSetzer")` to the consuming target.
The repository is public; HTTPS source access needs no GitHub authentication.
The tag is the package version. GitHub's ZIP/tar.gz downloads contain source
only; no application build or binary asset is uploaded.

## Adopting the extensions

Strict CommonMark and GFM profiles remain unchanged. To enable an M5 feature,
both select its `ExtensionConfiguration` in a profile and supply its
implementation to `MarkdownParser`. Supply only the desired implementations.
Keep node indices/ranges with the returned snapshot: transforms can rebuild
the tree, and cached result identity now reports `0.5.0`.

The umbrella product supplies `FootnotesHTMLRenderer` and
`AdmonitionHTML.renderer`. Math presentation and front-matter omission remain
explicit caller policies. Existing safe URL/raw-HTML settings and caller hook
trust boundaries continue to apply. Styling, themes and app adapters belong
to consumers.

## Scope and limitations

These are documented extension grammars, not complete GitHub/Pandoc/Obsidian
compatibility. Front matter is not deserialised. Footnote continuation lines
require explicit indentation. Single-dollar math stays on one physical line;
formula typesetting needs a caller engine. Callout type identifiers are ASCII,
and nesting support is broader than GitHub's documented site policy. Native
analysis remains a small optional rule subset and keeps custom bodies opaque.

M5 functional acceptance is documented in
[M5Acceptance](https://github.com/kerker00/GMSetzer/blob/v0.5.0/Docs/M5Acceptance.md).
Fresh selected-extension performance/allocation measurements, broader fuzzing,
minimum Apple runtime/device checks and consumer UI acceptance remain separate
M6/consumer work. This preview makes no new speed or app-integration claim.

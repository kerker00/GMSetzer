# Agent instructions

Read and follow [CLAUDE.md](CLAUDE.md) before working in this repository.
It contains the shared project rules for Codex and Claude.

Every new AI-assisted commit and PR description must credit the tools that
actually contributed. Use `Assisted-by: Codex (OpenAI)` for Codex and
`Assisted-by: Claude (Anthropic)` for Claude. If both contributed, include both
trailers after a blank line at the end of the commit message. This applies to
code, documentation, fixes and cleanup work.
